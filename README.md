# ANI:LOG

観たアニメ・観ているアニメ・気になるアニメを記録する、ブラウザだけで動くアニメ視聴管理アプリです（単一HTMLのSPA）。
視聴記録はブラウザの localStorage にだけ保存され、サーバーには送信されません。

**Webで使う：** https://amepom19-sudo.github.io/anilog/

## 使い方（Windows）

| ファイル | 役割 |
|---|---|
| `open_anilog.vbs` | ローカルサーバー（必要なら起動）＋既定のブラウザで開く |
| `start_anilog.vbs` / `start_anilog.bat` | ウィンドウなしでサーバーを起動してブラウザで開く |
| `anilog_server.vbs` | サーバーだけを起動（スタートアップ登録用） |
| `stop_anilog.bat` | サーバーを停止 |

サーバーは `python -m http.server 8765 --bind 127.0.0.1` です。
localStorage はオリジン（ホスト＋ポート）単位なので、ポート `8765` は変えないでください。

## 主な機能

- 作品検索・シーズン別一覧・ランキング（作品データ：[Tenrai API](https://api.tenrai.org/documentation)、非公式MyAnimeListデータ）
- マイリスト（見てる／見たい／見た／一時中断／視聴中止）、視聴話数、★評価（視聴中でも可）、メモ
- 今日の放送・週間スケジュール
- 配信先リンク、日本の配信サービスの検索リンク、作品ごとの視聴サービス設定
- 共有URL（データをURLに埋め込み、長い場合は自動分割）
- バックアップの書き出し／読み込み、フォルダへの自動バックアップ（Chrome / Edge）
